# Questionário para clientes (F14) — quem distribui: Manon

Formulário online (Google Forms ou similar), 12 perguntas, ~3 minutos. Meta: **50 respostas** de mulheres de 20 a 69 anos que moram ou trabalham na Tijuca ou em Copacabana. Não pedir nome, telefone ou endereço.

## Texto de convite (WhatsApp / Instagram)

> Oi! Estou abrindo um salão na [Tijuca/Copacabana] e queria ouvir quem mora ou trabalha por aqui. São 12 perguntas rápidas (3 min), sem identificação: [link]. Muito obrigada! 💛

## Perguntas

1. Você mora ou trabalha em: ( ) Tijuca/Praça da Bandeira/Maracanã ( ) Copacabana/Leme ( ) Botafogo/Humaitá ( ) Outro
2. Sua idade: ( ) 20–29 ( ) 30–39 ( ) 40–49 ( ) 50–59 ( ) 60–69
3. Com que frequência você faz **unhas (mão e/ou pé)**? ( ) Toda semana ( ) A cada 15 dias ( ) Uma vez por mês ( ) Raramente ( ) Nunca
4. E **cabelo** (corte, escova, cor, tratamento)? ( ) Toda semana ( ) A cada 15 dias ( ) Uma vez por mês ( ) A cada 2–3 meses ( ) Raramente
5. E **sobrancelha / cílios / depilação**? ( ) Todo mês ( ) A cada 2–3 meses ( ) Raramente ( ) Nunca
6. Quanto você gasta por mês, em média, com salão? ( ) Até R$ 100 ( ) R$ 101–200 ( ) R$ 201–400 ( ) R$ 401–700 ( ) Mais de R$ 700
7. Onde você faz hoje? ( ) Salão de bairro ( ) Rede/franquia ( ) Shopping ( ) Profissional em casa/domicílio ( ) Esmalteria
8. O que mais te incomoda no salão atual? (até 2) ( ) Atraso/espera ( ) Preço ( ) Higiene/esterilização ( ) Não ter horário à noite ou sábado ( ) Difícil marcar ( ) Resultado irregular ( ) Ambiente

10. Você pagaria a mais por um horário **até 21h** em dia útil? ( ) Não ( ) Até 5% ( ) 5–10% ( ) Mais de 10%
11. Um **clube de unhas** (ex.: 4 mãos e pés por mês com preço fechado) te interessaria? Quanto pagaria por mês? ( ) Não ( ) Até R$ 150 ( ) R$ 151–220 ( ) R$ 221–300 ( ) Mais de R$ 300
12. Quanto você paga hoje em: corte feminino R$ ___ · escova R$ ___ · mão e pé R$ ___ · design de sobrancelha R$ ___ (deixe em branco o que não faz)
